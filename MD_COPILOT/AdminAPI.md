| Operazione | Strict Consistency (Sincrono - Immediato) | Eventual Consistency (Asincrono) |
| :--- | :--- | :--- |
| **POST /admin/books**<br>(Nuovo Libro) | **MONGO:**<br>- Insert in books collection.<br>**NEO:**<br>- Create `(:Book)` Node.<br>- Create Relation `(:Author)-[:WROTE]->(:Book)`. | (Nessuna azione) |
| **PUT /admin/books/{id}**<br>(Update Info) | **MONGO:**<br>- Update Document Master in books collection.<br>**NEO:**<br>- Update property `b.title` sul nodo. | **NESSUNA AZIONE.**<br>(Le copie del titolo nelle review e bookshelf restano col vecchio nome come dato storico). |
| **DELETE /admin/books/{id}**<br>(Soft Delete) | **MONGO:**<br>- Set `status: "ARCHIVED"` in books collection.<br>**NEO:**<br>- DETACH DELETE nodo Libro (per bloccare raccomandazioni). | **NESSUNA AZIONE.**<br>(Il libro resta visibile nelle librerie utente e nelle review esistenti). |
| **POST /admin/authors**<br>(Nuovo Autore) | **MONGO:**<br>- Insert in authors collection.<br>**NEO:**<br>- Create `(:Author)` Node. | (Nessuna azione) |
| **PUT /admin/authors/{id}**<br>(Update Info) | **MONGO:**<br>- Update Document Master in authors collection.<br>**NEO:**<br>- Update property `a.name` sul nodo. | **NESSUNA AZIONE.**<br>(I nomi embedded nei libri e nelle review restano invariati). |
| **DELETE /admin/authors/{id}**<br>(Soft Delete) | **MONGO:**<br>- Set `status: "ARCHIVED"` in authors.<br>**NEO:**<br>- DETACH DELETE nodo Autore (o rimozione label). | **NESSUNA AZIONE.** |
| **DELETE /admin/reviews/{id}**<br>(Moderazione) | **MONGO:**<br>- Delete Document in reviews.<br>- `$pull` da `review_ids` e snapshots in books.<br>**NEO:**<br>- Detach Delete Node. | **MONGO:**<br>- Update stats in books e authors.<br>- `$pull` da `review_ids` e `reviews_year` in users.<br>*(Pulizia per rimozione contenuto tossico)*. |
| **PATCH /admin/users/{id}/ban**<br>(Ban Utente) | **MONGO:**<br>- Set `status: "BANNED"` in users.<br>**NEO:**<br>- Set label `(:BannedUser)`. | **MONGO (Cleanup):**<br>- Set `is_banned: true` su reviews.<br>- `$pull` review dagli snapshots dei libri. |
| **POST /admin/genres**<br>(Nuovo Genere) | **NEO:**<br>- Create `(:Genre)` Node. | (Nessuna azione) |
